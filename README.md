# thelia-ddev

DDEV stack for **Thelia 2.x only**.

This stack targets Thelia 2.6: PHP 8.2, the Smarty back office and the `thelia:install` CLI. It does not work with Thelia 3.

For Thelia 3, follow the DDEV guide in the documentation: https://doc.thelia.net/docs/getting-started/ddev

## Usage (Thelia 2.x)

`git clone https://github.com/thelia/thelia-ddev.git .ddev`  
`ddev start`  
`ddev setup`
